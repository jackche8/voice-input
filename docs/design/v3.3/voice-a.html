显示的数据（全部为现有事件，无新增数据）

  • recording：进入录音，前端本地秒表计时（与现有 _record_tick_timer 相同）
  • partial.stable_text 白色 #f8fafc；partial.tail_text 灰色 #94a3b8 + 虚线下划线
  • polishing：状态列转为蓝色旋转弧 + “润色”
  • typed.text：最终文字替换字幕，状态列绿色 ✓ “已输入”
  • error.message：单行胶囊（录音中也一样，出错即结束本次录音）
  • history_write_failed.message（警告）：不在录音中 → 单行警告胶囊；录音中 → 底栏上沿的附加提示行（见下方规格）
  • delivery_unknown.job_id / text：可点击确认卡片

QPainter 实现要点

  • 窗口按最大尺寸（838 × (24 提示行 + 86 两行字幕)）固定创建、透明穿透；动画只改 paintEvent 里的绘制矩形，不逐帧 setGeometry（XWayland 下逐帧改几何会抖）
  • 一个 QVariantAnimation 驱动 QRectF（胶囊 ↔ 字幕条形变），一个驱动整体透明度（painter.setOpacity，不用 windowOpacity）
  • 新确认的字：记录 [旧 stable 长度, 新 stable 长度) 区间与开始时间，按进度在 tail 色和 stable 色之间插值，分三段 drawText
  • 上卷：行数增加时，所有行 y 偏移从一行高度动画到 0，裁剪到文字区；被顶出的行同时淡出
  • 录音点呼吸、润色弧旋转：一个 16ms QTimer 只在可见且有动画时运行，空闲即停
  • ✓ 用 QPainterPath + 虚线偏移（QPen.setDashOffset）做描边出现

附加提示行（录音中到来的提示）

项规格
触发只承接警告类提示：状态为录音中（mode == "recording"）时收到 history_write_failed（show_toast(kind="warn")）；不切换状态、不停秒表、不动字幕和底栏几何
位置底栏上沿外侧；左缘 = 底栏左边 + 16px（底栏变宽变窄时跟随）；比底栏窄 32px 以上放不下时水平居中；下边与底栏上沿相接
尺寸 / 形状高 24px，左右内边距 10px，上两角圆角 8px，下边不画边线
字号 / 文字色FS_XS 12px Medium，CAPSULE_TEXT_HEX #e6edf3
底色CAPTION_BG_RGBA (13,17,23,240)，与底栏同色
颜色（warn）7px 圆点与 1px 描边用 STATE_WARN_HEX #d29922（描边透明度 60%）
时长淡入 160ms（同时升起 4px）→ 从出现算起 3000ms 开始淡出 → 淡出 260ms
多条 / 结束新提示替换旧提示并重新计时；新一次录音开始时清空；底栏整体淡出时随之消失
不在录音中警告 toast 保持原表现：切换为单行警告胶囊
  • QPainter：开口 QPainterPath（左下 → 左上圆角 → 右上圆角 → 右下），fillPath 自动闭合填充、strokePath 不画下边；填充盖住底栏上沿那段 1px 边线，看起来与底栏连成一体
  • 提示只记 {文字, 类型, 开始时间}，透明度由 painter.setOpacity 按时间算；一个 QTimer.singleShot(3000) 开始淡出，淡出结束清空；与录音秒表、字幕状态互不影响
  • show_toast 开头判断 mode == "recording" and kind == "warn" 时改为记录提示后返回，公共签名不变；提示行本身不需要改 event_stream.py
  • 提示行画在窗口固定尺寸内的上方 24px，不改窗口几何

超宽屏适配与取舍

  • 状态与文字都在屏幕中线，3440 宽下视线不用在左下角和中间来回跳
  • 宽度 480–838px（约屏宽 14%–24%），字号沿用 19px
  • 非语音的警告提示也出现在同一位置：不在录音中以胶囊形态显示，录音中以附加提示行显示
  • 取舍：贴屏幕底部，会盖住最大化窗口最底部约 80px（与现状相同）
