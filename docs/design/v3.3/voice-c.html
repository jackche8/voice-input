显示的数据（全部为现有事件，无新增数据）

  • partial.stable_text 白字、tail_text 灰字，均带深色描边；新出现的字逐个上浮淡入
  • 光带脉冲：每收到一条 partial 从中心向两端扩散一次（表示“正在识别”，不是音量）
  • recording 秒表、polishing（蓝色流光）、typed.text（绿色，显示最终文字）、error.message（红色）
  • busy / history_write_failed：单行字幕 + 对应颜色光带；delivery_unknown：确认卡片

触发的动作

  • 只有「投递未确认」卡片可点击：重新输入 → on_decision(job_id, True)；忽略 → on_decision(job_id, False)
  • 其余状态鼠标穿透、不抢焦点

基于哪些现有文件改造

  • _ui_desktop/voice_hud.py：公共方法不变；左下角胶囊并入光带两端（状态图标 + 秒表 / 状态字）
  • _ui_desktop/caption_bar.py：compute_trailing_two_lines 复用，行宽改为 1200、字号 26px；去掉圆角底框，改为描边字 + 径向暗角
  • _ui_desktop/theme.py：沿用 STABLE_TEXT_HEX / TAIL_TEXT_HEX / STATE_*；需新增令牌：字幕描边色、暗角色、26px 字号
  • _desktop/event_stream.py：不变

QPainter 实现要点

  • 描边字：QPainterPath.addText → strokePath（4px，RoundJoin，rgba(0,0,0,0.8)）→ fillPath；路径按文字变化缓存，不逐帧重建
  • 暗角：QRadialGradient + painter.scale(1, ry/rx) 画椭圆，中心 rgba(0,0,0,0.45) → 边缘 0
  • 逐字浮现：记录新增字的区间和时间，区间内的字单独画（每字延迟 25ms，160ms 上浮 6px + 淡入）
  • 光带：3px 圆角条 + QLinearGradient 高光块；脉冲位置 = 中心 ± p × 半宽
  • 窗口固定 1300×160 底部居中、透明穿透；只在可见且有动画时开 16ms QTimer

动效参数

动作时长曲线
出现：光带从中心长出 + 淡入240msOutCubic
新字上浮淡入（逐字错开 25ms）160msOutCubic
新行：整体上移一行，顶行淡出220msOutCubic
partial 脉冲（中心 → 两端）600msOutCubic
润色流光（左 → 右）1.1s 周期线性
已输入保持 → 字上移 10px 淡出、光带向中心收拢1.5s → 320msOutCubic

超宽屏适配与取舍

  • 3440 宽下字幕最宽 1200px（约屏宽 35%）、26px，一眼能读完两行
  • 没有底框，遮挡感最轻；描边 + 暗角保证浅色和深色背景都清楚
  • 取舍：描边字比纯色底框更费绘制；遮挡的是屏幕底部约 150px 高的区域，盖到最大化窗口底部输入框时也能透过看到
