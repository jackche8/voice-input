排版规则（逐行槽位，OCR 与翻译共用一套）

      
    
        
  • 每个原文行是一个“槽位”：位置 = 行框左上角，高度 = 行框高
    • 
        
  • OCR：第 i 行文字放第 i 个槽位，换行、缩进、段间距天然保留
    • 
        
  • 行宽对齐：某行要画的文字与原行相同（OCR 的全部行、翻译里没变的代码行 / 文件名）时，按原行框宽度微调字距（QFont.setLetterSpacing，限 −10%～+30% 字号），字落在原字的位置上，不会在行尾露出原文“回声”
    • 
        
  • 翻译：译文按 \n 切成硬行；每个硬行从下一个空槽位开始，用该槽位的 x（保留缩进）、原文字号，在段落右边界内折行，折出的部分依次占用后面的槽位
    • 
        
  • 段落整段翻译 → 一个硬行，从第一行开始排；代码 / 菜单 → 硬行数与原行数相同，一行对一行
    • 
        
  • 槽位用完仍有文字：按原行距继续向下排（不确定点：是否先降字号，见报告）
