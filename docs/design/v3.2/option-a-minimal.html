Architecture Overview — Release v3.2

When a user selects a region on Wayland, the compositor captures the frozen frame via xdg-desktop-portal and renders the translated text directly over the selected coordinates.

$ systemctl --user status ollama-voice-daemon.service

All OCR and LLM inference stays strictly on localhost without external API calls.
