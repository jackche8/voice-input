QPainter 实现要点

  • 标注 = 操作列表 [{type, 点, 色, 粗细, 文字}]；撤销 = 删最后一个后从冻结图重放全部操作（马赛克依赖它之前的结果，不能单独擦除）
  • 矩形 drawRect（RoundJoin）；箭头 = drawLine 到箭头底 + drawPolygon 三角（长 4w+8、半角 25°）
  • 文字输入：点击处放一个无边框 QLineEdit（透明底、字色与导出字体相同，WA_InputMethodEnabled=True 支持中文输入法），自动聚焦；Enter 或点别处提交为文字操作并销毁编辑框，Esc 取消本次输入。浮窗本体仍关闭输入法
  • 马赛克：取当前合成图该矩形 QImage.copy(rect) → scaled(w/b, h/b, SmoothTransformation)（块内求平均）→ scaled(w, h, FastTransformation)（最近邻放大成色块）→ 画回原位；按图像像素计算，HiDPI 用 devicePixelRatio 换算
  • 导出：合成图 QImage（冻结图原分辨率）→ PNG bytes → 回调；剪贴板写图片由业务层做
  • 光标：矩形 / 箭头 / 马赛克用十字，文字用 I 形；框外普通箭头。颜色与粗细只影响之后新画的标注（已画的不变）
