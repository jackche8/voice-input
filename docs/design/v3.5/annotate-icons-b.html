触发的动作

  • 点 5 工具图标：展开/切换二级样式条（再次点当前工具收起）；马赛克隐藏色板仅显 3 档圆点 + px
  • 点 撤销图标：回退上一条已提交标注；空栈禁用置灰
  • 点 复制主钮（柔绿剪贴板对勾） 或非输入态按 Enter → on_copy_image(png) -> bool（成功关窗；失败主钮切红框 + 右侧状态栏提示「复制失败」1.5s）
  • 点 保存图标 → on_save_image(png) -> SaveResult（成功显示路径 2.5s 自动关闭；失败留窗报因）
  • 点 取消图标 × 或非输入态按 Esc → close() → on_closed()（输入中 Enter 提交、Esc 仅取消输入）

模板 B 推荐理由与顺序对比

  • 一屏一主钮：柔绿 32×28px 剪贴板对勾把最高频动作「复制并关闭 (Enter)」与左侧蓝色激活工具自然分流，首次上手零学习成本
  • 防误触设计：取消 × 静息不喧宾夺主，悬停即转柔红警示，避免与邻近保存/复制误点
  • 动作顺序对比：保持现行 复制 保存 │ 取消 延续 v3.4/v3.5 肌肉记忆；备选顺序 保存 复制 │ 取消 可把绿色主钮挪到次靠右，若用户偏好可在定稿时 1 行调整
