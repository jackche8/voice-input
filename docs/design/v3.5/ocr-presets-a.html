前端触发动作日志（真实实现中预览与识别均由后端执行，配置变更经 POST /api/v1/config 回读确认）

1. 展示的数据字段

  • 配置预设列表：ocr_preprocess_presets[]（id、name、enabled、invert、contrast、brightness、sharpen、binarize_mode、threshold），启用上限 3。
  • 内置起步模板：starterTemplates[]（深底反色 / 低对比增强 / 强黑白二值化）。
  • 图片预览与识别结果：fileName、previewUrl、processedPreviewUrl、previewPhase、mode、lang_pair、ocr_text、text（译文）、ocrMeta（matched_preset_name、matched_rank、confidence、elapsed_ms、early_stopped、fallback_to_original、attempts[]）及四态 phase / error。

2. 触发的动作回调

  • onRequestPreprocessPreview({ file, params })：拖动滑块或切开关时防抖请求 POST /api/v1/ocr/preview，返回与正式识别同源的预览图。
  • onSubmitImage({ file, mode, lang_pair?, panel: "ocr", preprocess_params? })：携带 preprocess_params 时为「用当前参数试识别」；省略时按启用预设链路 1→2→3 顺序早停识别。
  • onSaveOcrPresets({ presets, action, targetId? })：新建/更新/删除（经确认框）/启停/上移下移调序，统一写入 POST /api/v1/config 并以服务端回读为准（非乐观更新）。
  • onCopy({ text, kind }) / onClearOcr() / onToggleTheme({ theme })。

3. 复用的现有界面、组件与文件

  • static/v3/css/theme.css & studio.css：直接沿用 .studio-window、7 项 .rail、.studio-split、.studio-box、.ocr-dropzone、.cap-seg、.switch、.rows 与 .v3-confirm。
  • static/v3/js/home.js：保持 activePanel === "ocr" 与全局 Ctrl+V 粘贴截图、拖拽选图、预览 URL 回收机制。
  • static/v3/js/confirm.js / icons.js / defaults.js / labels.js / business/home-controller.js / business/setup-actions.js。
