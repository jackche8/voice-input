前端触发动作日志（模拟后端响应 · 脱敏与排障汇总均由后端完成）

1. 展示的数据字段

  • 运行日志：sources[]（9 份 paths.logs 文件：name / label / lines / bytes / updated_at）、lines[]（后端脱敏文本）、total_lines、truncated、log_max_lines（500 | 2000 | 5000，默认 2000）、四态 phase 与 error/message。
  • 关于信息（后端权威下发）：app_name、version（单源 _version.APP_VERSION）、os_name / platform_detail / session_type、python_version、asr_variant（cuda | cpu | mps）、data_root / logs_dir / config_root、license（AGPL-3.0 + 商业授权）、links（仓库 / GitHub Pages / Releases / Issues）。

2. 触发的动作与建议接口

  • 切换/刷新日志 → onSelectLogSource(name) / onRefreshLogs()（建议 GET /api/v1/logs 与 GET /api/v1/logs/{name}）。
  • 修改保留上限 → onChangeLogMaxLines(500|2000|5000)（POST /api/v1/config，非乐观更新：等待服务端回写成功再确认）。
  • 复制与清空 → onCopyCurrentLog(name)、onCopyDiagnosticSummary()（建议 GET /api/v1/logs/diagnostic-summary 由后端统一拼接版本/平台/组件状态 + 脱敏尾行）、onClearCurrentLog(name)（经确认框触发 DELETE /api/v1/logs/{name}）。
  • 关于页复制 → onCopyAboutInfo()（读取 GET /api/v1/about 并由 clipboard.js 写入剪贴板）。

3. 复用的既有页面、组件与文件

  • static/v3/css/theme.css & studio.css：直接复用 Studio C 侧栏、.studio-box、.rows、.progress、.v3-confirm，零裸色值。
  • static/v3/js/labels.js & home.js：HOME_NAVS 由 5 项扩至 7 项，新增面板拆分独立纯 UI 模块（logs-panel.js / about-panel.js）避免 home.js 继续膨胀。
  • static/v3/js/icons.js & confirm.js：图标按既有 24×24 描边规范补 4 枚；清空日志直接复用 V3.mountConfirm。
  • static/v3/js/business/home-controller.js & clipboard.js、_version.py、_paths.py。
