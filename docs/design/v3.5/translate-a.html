前端触发动作日志（模拟后端响应 · 方向仅由后端判定并返回）

显示的数据

  • 配置态：translate_lang_pair（当前 "zh-en"，展示「中 ⇄ 英」）、translate_auto_enabled（默认 true）、langPairOptions（预留扩展）。
  • 后端译文态：text、source_lang、target_lang、direction_mode（auto / manual）、chunks（长文本分段数）、elapsedMs、error/message。方向完全以服务端返回为准。
  • 本地 UI 态：phase（空/加载/结果/错误）、debouncePending、manualOverride（null 或反转方向）。

触发的动作

  • 停顿 1s / Ctrl+Enter / 立即翻译 → onTranslateText({ text, lang_pair, source_lang?, target_lang? })；空输入不发请求，单调序号丢弃过期响应。
  • 点击 ⇄ 互换 → 临时锁定反转方向并立即重译；再次点击 ⇄ 或 清空输入 恢复自动判定。
  • 设置页开关 / 语言对 → onToggleAutoTranslate(bool) / onChangeLangPair(pair) 写入配置。
