触发的动作（含 Enter 复制）

  • Enter / Return（非文字输入态）或点复制 → on_copy_image(png) -> bool：成功立即关窗并回调 on_closed()；失败在卡片反馈「复制失败」1.5s 不关
  • Enter / Return（文字输入态）→ 先提交该段文字并退出输入态（不关窗）；再按 Enter 复制并关闭
  • Esc（文字输入态取消当次输入；非输入态关闭）或点取消 → close() → on_closed()
  • 点保存 → on_save_image(png) -> SaveResult：成功显示路径 2.5s 后关闭；失败显示原因不关
  • 颜色与粗细常驻可见，未选工具时也可预选颜色/粗细；选马赛克时 6 色点置灰禁用，保留占位
