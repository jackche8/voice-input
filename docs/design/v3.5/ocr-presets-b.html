前端触发动作日志（真实实现中预览与识别均由后端执行，配置写回后刷新态）

1. 展示的数据字段

  • 顶部链路与预设列表：ocr_preprocess_presets[]（id / name / enabled / invert / contrast / brightness / sharpen / binarize_mode / threshold）、启用计数（上限 3）与 1→2→3→原图兜底链路节点。
  • 对照画布与识别结果：previewUrl、processedPreviewUrl、previewPhase、mode、lang_pair、ocr_text、text、ocrMeta（含 attempts[] 与 fallback_to_original 兜底标记）。
  • 右侧参数检视器：starterTemplates[]（3 套起步模板）、editingPresetId、draft、校验错误与保存反馈。

2. 触发的动作回调

  • onRequestPreprocessPreview({ file, params })：右侧检视器参数变动时防抖调用 POST /api/v1/ocr/preview 刷新左侧处理图。
  • onSubmitImage({ file, mode, lang_pair?, panel: "ocr", preprocess_params? })：区分顶部「按启用预设链路识别」与右侧「当前参数试识别」。
  • onSaveOcrPresets({ presets, action, targetId? })：新建/更新/删除（经确认弹窗）/启停/上下移调序持久化至 POST /api/v1/config（非乐观更新）。

3. 复用的现有界面、组件与文件

  • static/v3/css/theme.css & studio.css：沿用 .studio-window、7 项 .rail、.studio-box、.cap-seg、.switch、.ocr-dropzone、.v3-confirm 与双主题令牌。
  • static/v3/js/home.js / confirm.js / icons.js / defaults.js / labels.js：在 activePanel === "ocr" 内拆出独立纯 UI 模块挂载，保留既有粘贴与选图流。
  • static/v3/js/business/home-controller.js / setup-actions.js / clipboard.js。
