触发的动作（含 Enter 复制）

  • Enter / Return（非文字输入态）或点复制 → on_copy_image(png) -> bool：成功立即关窗并回调 on_closed()；失败显示「复制失败」1.5s 不关
  • Enter / Return（文字输入态）→ 先提交该段文字并退出输入态（不关窗）；再按 Enter 复制并关闭
  • Esc（文字输入态取消当次输入；非输入态关闭）或点取消 → close() → on_closed()
  • 点保存 → on_save_image(png) -> SaveResult：成功显示路径 2.5s 后关闭；失败显示原因不关
  • 5 工具切换、6 色选色、3 档粗细、撤销均为浮窗局部状态；点框外仅提交编辑中文字，不误关浮窗

模板 A 参数与 PySide6 落地要点

  • 6 色预设：红 #ff2d2d（默认）、橙黄 #f59e0b、绿 #3fb950、蓝 #2f81f7、白 #f8fafc、黑 #111827；深色底上黑点加 1px 亮灰描边、选中态为 2px 蓝环 + 4px 反色中心点
  • 3 档粗细：细（线 2px / 字 16px / 马赛克 6px）、中（3px / 20px / 10px，兼容现行默认）、粗（6px / 28px / 16px）
  • 零抖动策略：单条结构无展开/收起层；马赛克态色点置灰禁用不隐藏；选中不加粗；实测整条宽度约 757px，窄选区时靠 place_menu 水平钳制不出屏
