前端触发动作日志（模拟后端响应 · 方向仅由后端判定并返回）

显示的数据

  • 原文面：translate_lang_pair（「中 ⇄ 英」）、translate_auto_enabled、debouncePending（贴边 2px 防抖轨）、字符数。
  • 译文面胶囊：后端返回的 source_lang、target_lang 与 direction_mode（auto 蓝胶囊 / manual 橙锁定胶囊 + 恢复按钮）。
  • 译文体：text、chunks、elapsedMs、error/message；加载态为保高骨架屏，错误态内嵌「重试翻译」。

触发的动作

  • 停顿 1s / Ctrl+Enter / 立即翻译 / 错误区重试 → onTranslateText({ text, lang_pair, source_lang?, target_lang? })；空输入不请求，单调序号防乱序。
  • 点击中轴 ⇄ → 临时锁定反转方向并立即重译；再次点击 ⇄、点胶囊内 × 恢复自动 或 清空 恢复自动。
  • 设置页开关 / 语言对 → onToggleAutoTranslate(bool) / onChangeLangPair(pair) 持久化到配置。
